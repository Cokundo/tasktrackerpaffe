# 💍 電撃婚ノート — 引き寄せの法則ちゃんぽん実践アプリ

引き寄せの法則の徹底ガイド（理屈編・実践メソッド編・失敗パターン編・恋愛結婚編・日本語圏の文脈編）を、
**結婚引き寄せ、それも電撃婚仕様**に落とし込んだブラウザアプリです。

`hikiyose/index.html` をブラウザで開くだけで動きます（ビルド不要・通信なし・記録は端末の localStorage に保存）。
パフェアプリとは完全に独立しているので、どちらを触っても互いに影響しません。

**1枚だけで動く版**：`dist/dengekikon-note.html`（134KB）。
このファイル1つをダウンロードしてダブルクリックすれば、リポジトリなしでも動きます。
作り直すときは `node tools/build-hikiyose.js`。

---

## 設計の方針

ガイドの通り、**流派どうしが矛盾したままちゃんぽん**にしてあります。統一していません。
その代わり、どの機能がどの系譜のものかをカードごとにタグで表示します。

| タグ | 系譜 | このアプリでの担当 |
|---|---|---|
| エイブラハム系 | 感情＝波動の指標 | 感情のスケール22段階、17秒・68秒タイマー |
| ネヴィル系 | 想定の法則 | SATS誘導、未来日記、「終わりに生きる」 |
| マーフィー系 | 潜在意識の書き換え | アファメーション、369、55×5、ブロック内観 |
| シークレット系 | イメージング＋感謝 | 感謝ワーク |
| 掲示板系 | なる／認識の変更／別の領域／自愛 | 鏡のワーク、淡々と気づく、自分単体の未来 |
| 日本の著者系 | 口ぐせ・手帳・決める | ありがとう500回、オーダー訂正、日付を決める |
| 現実的アプローチ | 行動はするが結果に執着しない | 先取り行動、48時間ルール、婚活併用 |

## 画面

### 今日
- **ステージ表示**（0〜4）と、次へ進むために足りていないもの
- **感情のスケール**（22段階）。押すと「今より一段だけ上」へ出るための足がかりが出ます。いきなり最上段は狙いません
- **自愛 — 鏡のワーク**（愛してる／完璧／最高／許可する）。自愛が苦手な人向けに〈許可する〉だけの入口あり
- **淡々と気づく**欄（ネガティブは許すのではなく気づくだけ）
- **夜のノート**（いいことノート3つ＋感謝3つ）
- 今日やった実践の一覧

### 決める
- **電撃婚を決める** — 入籍する日と「電撃度」（出会ってから入籍まで30〜365日）を設定。締切ではなく *すでに決まっている予定* として表示します
- **逆算ロードマップ** — 決めた日から逆算した道のり（出会う→付き合う→確信→将来の話→指輪→プロポーズ→顔合わせ→下見→入籍）。
  結婚指輪は受け取りまで1〜2か月かかる実務があるので、間に合わない日程だと自動で前倒しされ、時間順に並べ替わります
- **理想の相手リスト100項目** — 外見／性格／仕事・経済／価値観・生活／一緒にやりたいこと／**フィーリング** の6カテゴリ。
  フィーリングが10項目未満だと警告します（条件だけ追うと本当の願いとズレるため）。否定形で書くとその場で指摘します
- **アファメーション** — 主語・語尾・否定形・五感を自動採点。違和感スライダーが6以上だと、認知的不協和を避けるための**緩和形**（「〜になりつつある」等）を提案します

### 刷り込む
- **SATS** — 場面を登録して5ステップの誘導（体をゆるめる→重さ→場面→中に入る→静けさのまま眠る）。
  「プロポーズ」「号泣」など*叶った瞬間の歓喜*を場面に選ぶと、よくある失敗として指摘します
- **場面カード**6枚（朝のマグが二つ／歯ブラシが二本／玄関の鍵が二つ／二人分の洗濯物／夕飯の皿が二枚／隣の寝息）。
  押すと場面の文が入り、誘導の③以降は暗い画面にその線画が出ます。
  絵はすべて `js/scenes.js` のインラインSVGで、外部の画像を読みません（通信なしのまま動く）。
  あえて地味な日常の絵ばかりなのは作法の都合 ── 狙うのは歓喜ではなく静けさなので
- **369メソッド**（朝3・昼6・夜9）
- **55×5メソッド** — ワンオーダー制。5日連続で55回、達成すると1か月後の「オーダー確認日」が自動で決まります
- **17秒・68秒タイマー** — 「でも」が混ざったら〈混ざった〉でリセット
- **口ぐせ** — ありがとう500回カウンタと、ネガティブな口ぐせの「オーダー訂正」

### 手放す
- **手放しチェック** — 「結婚が叶わなくても、私は幸せです」と唱えて、穏やかさを0〜10で記録。推移をグラフ表示
- **結婚への隠れたブロック** 8種（独身のメリット／親の結婚観／父親との関係／過剰な自立／女性性の封印／想像すると怖い／年齢の焦り／幸せになっていいと思えない）。
  解除ではなく**気づく**ための問いつき
- 物理的な断捨離カウンタ
- 相手を頭から追い出して**自分単体の未来**を書く欄

### 動く
- **先取り行動**12種（指輪の試着、指のサイズ、ドレス、式場、内見、二つで一組の食器…）
- **48時間ルール**の行動ログ
- 婚活・アプリ併用の作法、「なる」の実務

### 記録
- 未来日記（過去形・完了形でチェック）
- 好転反応メモ（4週間で14日を超えると「立ち止まってください」を出します）
- **スマホとPCで引き継ぐ**（下記）
- 91日分のカレンダー、集計、書き出し／読み込み／全消去

## スマホとPCで引き継ぐ

記録は端末のブラウザ（localStorage）にしか入らないので、PCとスマホでは別々になります。
そこで**引き継ぎコード**を1本の文字列にして運びます。LINEのKeepメモ・自分宛のメール・メモアプリ、どれでも構いません。

1. 出すほうの端末で「記録」タブ →「引き継ぎコードを作る」→「コピー」
2. どこかに貼って、もう一方の端末で開く
3. 入れるほうの端末で「記録」タブの②に貼り付け →「合体させる」

**合体（マージ）** は、両方の端末についている記録を消さずに1つにまとめます。

| 種類 | どうなるか |
|---|---|
| 回数（自愛・369・55×5・ありがとう・断捨離・68秒） | 多いほうを残す |
| チェック（SATS・先取り行動・ロードマップ・ブロック） | 片方でも付いていれば付いたまま |
| 一覧もの（リスト・未来日記・自分単体・口ぐせ） | idで突き合わせて、足りないものだけ足す |
| 文章（いいことノート・感謝・好転反応メモ・場面） | 空でないほう。両方に中身があってぶつかったときだけ、**あとから触った端末**のほうを採る |
| 感情の段・手放しの穏やかさ | 同上（1日1つなので、ぶつかったら新しいほう） |

同じコードを2回入れても増えません（べき等）。上書きしたいときだけ「まるごと置き換え」を使ってください。

コードはgzipで縮めてからbase64にしているので、**半年みっちり記録しても4,000文字ほど**（生のJSONだと66,000文字）。
LINE1通に収まります。`CompressionStream` がないブラウザでは、縮めずに `HKY0:` 形式で出します。

JSONファイルでの書き出し／読み込みも残してあり、そちらも読み込み時に合体か置き換えかを選べます。

### 流派
5系譜の解説、用語の整理（引き寄せ／顕現／アファメーション／潜在意識書き換え）、
日本語圏の主要な書き手7名、用語辞典（なる・認識の変更・別の領域・ザ・チケット・自愛・タイムラグ…）、
**特定の相手 vs 相手を特定しない**の両論、失敗パターン、留意点。

## 自動で出る「ベンチマーク警告」

ガイドの「判断を変えるベンチマーク」を実装しています。

| 条件 | 出るもの |
|---|---|
| 直近1週間の感情の段が慢性的に下がった | 方法が合っていないサイン。刷り込みをやめて自愛に戻る |
| 焦り・心配の段が週4日以上 | 願望設定が他人軸になっていないか点検 |
| 好転反応の記録が4週間で14日超 | 立ち止まる。必要なら医療・専門家へ |
| 手放しの穏やかさが低いまま先取り行動だけ進む | ステージ3に戻る日を作る |

## ステージの進み方

| ステージ | 内容 | 次へ進む条件 |
|---|---|---|
| 0 | 土台づくり（自愛・いい気分） | 直近14日で自愛7日 かつ アファメーションの違和感5以下 |
| 1 | 願望の明確化 | リスト100項目・フィーリング10項目・アファメーション確定 |
| 2 | 潜在意識への刷り込み | 直近14日で刷り込み7日（SATS／369／55×5／68秒のいずれか） |
| 3 | 手放し・執着ケア | 穏やかさ7以上が3回 |
| 4 | 先取り行動と現実的行動 | 先取り行動3つ以上。ここから先は日常 |

条件は `js/store.js` の `stage()` / `stageGaps()` にまとまっています。

## カスタマイズ

- 感情スケールの文言・足がかり → `js/data.js` の `EMOTION_SCALE`
- ロードマップの段取りと逆算比率 → `js/data.js` の `ROADMAP`（`ratio` は電撃期間に対する割合、`lead` は納期の下限日数）
- 先取り行動・ブロックの問い・リストのカテゴリ → `PREACTIONS` / `BLOCKS` / `LIST_CATS`
- SATSの誘導文と秒数 → `SATS_STEPS`
- 言葉のチェック基準（否定形・願望形・五感語） → `js/checks.js`

## 留意点

このアプリは、引き寄せの実践者コミュニティ内部で語られる理論・作法を**内在的に**実装したものです。

- 波動・周波数・量子力学的な説明の多くは、当の実践者・情報源自身が「科学的に証明された話ではない」と但し書きを付けています
- 体験談は事後の自己解釈であり、成功例が選択的に語られやすいものです（生存者バイアス）
- 掲示板系の「達人」の語録は匿名の書き込みが原典で、まとめブログ経由の二次引用が中心です
- 「好転反応」と称して不調が長く続くときは、この枠組みから離れて医療・専門家にかかってください
- 高額なセッション・講座・情報商材への依存や、現実的な行動・専門的支援の放棄には注意してください

同じ内容がアプリの「流派」タブ末尾にも入っています。
