# 🍨 育てるパフェ — 7項目 成長グラフアプリ

**筋トレ・VBA・簿記・マナー・英語・脱毛・家事** の7項目をステータスとして持ち、
日々の達成を記録するほど、その人だけの姿をしたパフェへ育っていくアプリです。

`index.html` をブラウザで開くだけで動きます（ビルド不要・通信なし・記録は端末の localStorage に保存）。

---

## 7項目とその特徴

各ステータスには「特徴」が割り振られ、パフェの担当パーツになります。
どこを伸ばしたかが、そのままパフェの姿の違いになります。

| 項目 | 印 | 特徴 | パフェ上のパーツ | レベルが上がると |
|---|---|---|---|---|
| 筋トレ | 剛 | 力・ボリューム | そびえ立つプロテインクリーム | 背が伸び、渦の段数が増える |
| VBA | 巧 | 効率・自動化 | 幾何格子のウエハー | 本数が増え、格子の目が細かくなる |
| 簿記 | 律 | 正確・積算 | きっちり整列したグラノーラの地層 | 層が厚くなり、縞のブレが消えて整う |
| マナー | 雅 | 品格・所作 | 金縁のゴブレットとドイリー | 脚が伸び、金の縁取り・レースが現れる |
| 英語 | 彩 | 越境・彩り | 世界のフルーツ | 果実の種類と数が増える |
| 脱毛 | 透 | 透明感・なめらかさ | 澄んだジュレの層 | 濁りが晴れ、艶と気泡のきらめきが増す |
| 家事 | 暖 | 整え・温かみ | 白いソースと仕上げの粉雪 | ミント・粉糖・全体の輝きが加わる |

パフェはCanvasに毎フレーム描き直されるため、レベルが上がるとその場で姿が変わります。
上位2ステータスから **固有のパフェ名**（例：`伝説の鋼塔パフェ 〜ロジック格子添え〜`）も自動生成されます。

## 成長のしくみ

- 1項目の達成で **+10 XP**。
- 連続記録日数に応じたボーナス（2日目から、最大 +10 XP／項目）が加算されます。
- XPが貯まると **Lv.1 〜 Lv.20** まで成長し、レベル帯ごとに称号が変わります
  （例：筋トレ … なまり肉 → 目覚めた筋繊維 → 鍛錬者 → 鋼の躰 → 筋肉神）。
- レベル L → L+1 に必要なXPは `30 + 10 × L`。
- XPは常に**記録（ログ）から再計算**されるため、チェックを外せばXPも正しく戻ります。

### 画面

- **あなたのパフェ** … 現在の姿・パフェ名・構成パーツ一覧／PNG保存
- **今日の達成** … 7項目のチェック、獲得XP、今日のひとことメモ
- **成長グラフ** … 7角形のレーダーチャート（アニメーション付き）
- **ステータスと特徴** … 項目ごとのレベル・称号・XPバー・担当パーツ
- **この30日の記録** … 達成数のヒートマップ、記録日数・のべ達成・最長連続・総XP
- ヘッダー … 総レベル／連続日数／**調和度**（7項目が均等に育つほど高い）

## 使い方

```bash
# 依存なし。ファイルを開くだけ
open index.html          # macOS
xdg-open index.html      # Linux
```

記録はブラウザの localStorage（キー `growth-parfait-v1`）に保存されます。
端末を移すときは「データ書き出し」でJSONを保存し、移行先で「読み込み」してください。

## ファイル構成

```
index.html        画面の骨組み
css/style.css     スタイル（ダークモード対応・レスポンシブ）
js/data.js        7項目の定義、レベル計算、パフェ名の生成
js/store.js       記録の保存とXPの再計算（連続日数・集計）
js/radar.js       成長グラフ（レーダーチャート）
js/parfait.js     パフェの描画（すべてCanvasで手描き）
js/app.js         画面の組み立てとイベント
```

## カスタマイズ

- 項目・特徴・称号・色を変えたい → `js/data.js` の `STATS` を編集
- XPの伸び方を変えたい → `js/data.js` の `BASE_XP` / `xpToNext()` / `streakBonus()`
- パフェの見た目を変えたい → `js/parfait.js`（各パーツが1メソッドに分かれています）
