# 🍨 育てるパフェ — 7項目 成長グラフアプリ

**筋トレ・VBA・簿記・マナー・英語・脱毛・家事** の7項目をステータスとして持ち、
日々の達成を記録するほど、その人だけの姿をしたパフェへ育っていくアプリです。

`index.html` をブラウザで開くだけで動きます（ビルド不要・通信なし・記録は端末の localStorage に保存）。

---

## 7項目とその特徴

各ステータスには「特徴」が割り振られ、パフェの担当パーツになります。
どこを伸ばしたかが、そのままパフェの姿の違いになります。

| 項目 | 印 | 特徴 | パフェ上のパーツ | レベルが上がると |
|---|---|---|---|---|
| 筋トレ | 剛 | 力・ボリューム | てっぺんの生クリーム | 大きくなり、Lv6でさくらんぼ付きに |
| VBA | 巧 | 効率・自動化 | 狐プレート | 枚数が増え、Lv7でロールクッキー、Lv13でプレッツェル |
| 簿記 | 律 | 正確・積算 | チョコフレークの地層 | 層が厚くなり、Lv10でブラウニーが重なる |
| マナー | 雅 | 品格・所作 | レースの席と金縁の器 | Lv1席の明かり→Lv3金の縁→Lv6金の受け皿→Lv9太い縁→Lv12スプーン→Lv16二重の縁→Lv19きらめき |
| 英語 | 彩 | 越境・彩り | 世界のフルーツ | 3レベルごとに果物が1種増える（全7種） |
| 脱毛 | 透 | 透明感・なめらかさ | クリスタルと花ゼリー | Lv7で花ゼリー、Lv14でかき氷が重なる |
| 家事 | 暖 | 整え・温かみ | アイシングクッキーと甘味 | Lv2でクッキー、Lv8で団子、Lv14でチョコツイスト |

**器の満ち具合**は簿記・脱毛・家事の合計で決まり、育つほどグラスが満たされて、
やがてクリームが口からあふれます。どのレベルで何が変わるかは `js/data.js` の `STAGES` にまとまっていて、
ステータス欄には「次の変化 Lv.◯ …」として表示されます。上位2ステータスから **固有のパフェ名**
（例：`伝説の鋼塔パフェ 〜ウエハース添え〜`）も自動生成されます。

## 抹茶ラテ — 継続のメモリ

パフェとは別に、**サボりを映す抹茶ラテ**があります。7メモリから始まります。

| できごと | メモリ |
|---|---|
| 1日まるごとサボる（どの項目も0） | **−1** |
| 7日サボる | **空になる** |
| 皆勤（その日7項目すべて達成）を2日 | **+1**（上限7） |

- 今日サボっていても、日付が変わるまでは減りません。**今日ひとつでも達成すれば減少は止まります。**
- 空（0メモリ）になっても、そこから下がることはありません。皆勤2日ごとに1メモリずつ戻せます。
- 「皆勤」の判定を変えたいときは `js/data.js` の `PERFECT_NEEDED`（既定 7項目）と
  `PERFECT_FOR_HEAL`（既定 2日）を書き換えてください。

カップの絵は7コマのドット絵（`assets/parts/matcha_0〜6.png`）を残量に応じて差し替えています。
下のドットが残りメモリ、満タンのときは湯気、今日まだ0項目のときは「次に消えるメモリ」が点滅します。
ヘッダーにも残りメモリが出て、残りわずか／空のときは色が変わります。

## スペシャル実績 — どデカトッピング

日々の積み上げとは別枠の「大勝負」を4つ用意しています。
達成すると、規格外の大きさのトッピングがパフェに載ります。

| 実績 | どデカトッピング | ボーナス |
|---|---|---|
| VBAベーシック取得 | 特大ワッフルクッキー | VBA +200 XP |
| 簿記3級取得 | 特大チーズケーキ | 簿記 +200 XP |
| TOEIC点数更新 | 地球グミ（更新ごとに星が増える／スコア表示付き） | 英語 +150 XP／回 |
| Unityゲーム 1画面完成 | ダブルスクープのチョコミントアイス（てっぺんに載る） | VBA +200 XP |

- タイルをタップで達成を記録。TOEICはスコアを入力でき、**何度でも更新**できます（更新回数ぶん星が増える）。
- 取り消しはタイル右上の `×`。
- 実績を持っていると、パフェ名の頭に `〈3冠〉` のように付きます。

## 成長のしくみ

- 1項目の達成で **+10 XP**。
- 連続記録日数に応じたボーナス（2日目から、最大 +10 XP／項目）が加算されます。
- XPが貯まると **Lv.1 〜 Lv.20** まで成長し、レベル帯ごとに称号が変わります
  （例：筋トレ … なまり肉 → 目覚めた筋繊維 → 鍛錬者 → 鋼の躰 → 筋肉神）。
- レベル L → L+1 に必要なXPは `30 + 10 × L`。
- XPは常に**記録（ログ）から再計算**されるため、チェックを外せばXPも正しく戻ります。

### 画面

- **あなたのパフェ** … 現在の姿・パフェ名・構成パーツ一覧／PNG保存
- **今日の達成** … 7項目のチェック、獲得XP、今日のひとことメモ
- **成長グラフ** … 7角形のレーダーチャート（アニメーション付き）
- **抹茶ラテ** … 継続のメモリ（サボると減り、皆勤で戻る）
- **スペシャル実績** … 4つの大勝負とその達成状況
- **ステータスと特徴** … 項目ごとのレベル・称号・XPバー・担当パーツ
- **この30日の記録** … 達成数のヒートマップ、記録日数・のべ達成・最長連続・総XP
- ヘッダー … 総レベル／連続日数／**調和度**（7項目が均等に育つほど高い）／抹茶ラテの残り

## 使い方

```bash
# 依存なし。ファイルを開くだけ
open index.html          # macOS
xdg-open index.html      # Linux
```

記録はブラウザの localStorage（キー `growth-parfait-v1`）に保存されます。
**記録は端末の中だけ**にあり、どこにも送信されません（通信するコードはありません）。
端末を移すときは「データ書き出し」でJSONを保存し、移行先で「読み込み」してください。

### 1枚だけで動くアプリ版

`dist/ikuteru-parfait.html` は CSS・JS・素材をすべて埋め込んだ**単体ファイル**です。
ダウンロードしてダブルタップ／ダブルクリックで開くだけで、サーバーもネットも要りません。

```bash
node tools/build-standalone.js   # 更新したら作り直す
```

- リポジトリを **private** にすると（無料アカウントでは）GitHub Pages は止まりますが、
  このファイルを端末に置いておけば今までどおり使えます
- `file://` で開いても **「画像として保存」まで動きます**（素材を埋め込んでいるため、
  フォルダ版で起きるブラウザの制限を受けません）
- 記録は開いたブラウザの localStorage に入ります。フォルダ版・Pages版とは別枠になるので、
  移すときは「データ書き出し／読み込み」を使ってください

## ファイル構成

```
index.html         画面の骨組み
dist/              1枚で動くアプリ版（配布用・ビルド結果）
css/style.css      スタイル（ダークモード対応・レスポンシブ）
js/assets.js       パフェ素材の読み込み
js/data.js         7項目の定義、レベル計算、パフェ名の生成
js/store.js        記録の保存とXPの再計算（連続日数・集計）
js/radar.js        成長グラフ（レーダーチャート）
js/matcha.js       抹茶ラテのメモリ表示
js/parfait.js      パフェの組み立て（素材の配置＋実績トッピングの描画）
js/app.js          画面の組み立てとイベント
assets/raw/        元のドット絵素材（背景あり・アップロードしたまま）
assets/parts/      背景を抜いて切り詰めた素材（アプリが読むのはこちら）
tools/build-standalone.js  1枚だけで動くHTMLを書き出すツール
tools/make-assets.js       背景透過ツール
tools/make-matcha-frames.js  抹茶ラテのスプライトシートを1コマずつに切り出すツール
tools/asset-map.json       元ファイル名 → 素材名としきい値の対応表
```

## 素材について

パフェはドット絵素材を積み上げて描いています。元画像は背景付き（白・黒・灰・市松）なので、
`tools/make-assets.js` で自動的に背景を抜いています。

```bash
npm i playwright          # 変換にだけ必要
node tools/make-assets.js # assets/raw → assets/parts
```

- 画像の外周から背景色を推定し、**外周と地続きの領域だけ**を透明化するので、
  素材の内側にある白（クリームなど）は残ります
- 素材ごとのしきい値は `tools/asset-map.json`（`near` / `far` / `erode`）で調整できます
- グラスだけは中身を透かすため、白を全面的に抜く `colorkey` 指定です
- 新しい素材を足すときは `assets/raw/` に置き、`asset-map.json` に1行足して再実行
- 抹茶ラテのカップはマゼンタ背景のスプライトシート（`assets/raw/matcha_sheet.png`）で、
  `node tools/make-matcha-frames.js` が7コマに切り分けます（色かぶりも落とします）

> フォルダ版の `index.html` を `file://` で直接開くと、ブラウザの制限で「画像として保存」だけ使えません。
> `python3 -m http.server` 経由で開くか、素材を埋め込んだ `dist/ikuteru-parfait.html` を使ってください。

## カスタマイズ

- 項目・特徴・称号・色を変えたい → `js/data.js` の `STATS` を編集
- スペシャル実績を足したい／文言を変えたい → `js/data.js` の `MILESTONES`
  （トッピングの絵は素材を `assets/raw/` に足して `js/parfait.js` の `drawSpecials()` で配置）
- XPの伸び方を変えたい → `js/data.js` の `BASE_XP` / `xpToNext()` / `streakBonus()`
- パフェの盛り付けを変えたい → `js/parfait.js` の `drawContents()` / `drawTop()`
  （どの素材をどのレベルで出すかが並んでいます）
