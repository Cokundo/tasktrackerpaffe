# 凪（nagi）— 衝動の波をやり過ごすアプリ

すぐ刺激が返ってくるものに手が伸びそうになったとき、
**衝動が来てから動くまでの10分間を一緒に過ごす**ためのアプリです。
止める檻ではなく、波を越えるための足場として作っています。

`nagi/index.html` をブラウザで開くだけで動きます（ビルド不要・通信なし）。
記録はその端末の localStorage にだけ保存され、どこにも送られません。
パフェアプリとは完全に独立していて、保存データも別です。

スマホでは「ホーム画面に追加」するとアプリのように開けます（https で配信している場合はオフラインでも開けます）。

## 画面

| タブ | できること |
|---|---|
| 波 | 「今、来てる」を押す → 状態と強さを選ぶ → 10分タイマーと代わりの行動が出る → 終わったら「越えた／今回は流れた」を記録。途中でアプリを閉じても続きから再開します |
| 箱 | 出し切り箱。浮かんだ展開や台詞を3行だけ書いて封じる。中身は普段は閉じて表示されます |
| 朝 | 朝アンカー。今日か明日の「最初の2時間」を決めておくと、朝のうちは「波」の画面に表示されます。金・土の夕方以降、翌朝が未定なら声をかけます |
| 記録 | 7/30/90日の波の数、きっかけ・時間帯・曜日ごとの傾向、効いた代わりの行動。責める言葉は出しません |
| 守る | 買わずに守れた金額、24時間保留箱（24時間たつまで「買う」を押せない）、守りたいお金の目標、鍵を自分以外に預けるチェックリスト |
| 設定 | 状態ごとの代わりの行動の編集、記録の書き出し・読み込み、全消去 |

## いじりたいとき

- 状態の種類や、代わりの行動の初期値 → `js/data.js` の `STATES` / `DEFAULT_ESCAPES`
- タイマーの長さ → `js/data.js` の `WAVE_MINUTES`
- 波のあとの一言 → `js/data.js` の `AFTER_WORDS_OK` / `AFTER_WORDS_NG`
- 保存の形 → `js/store.js` の `Store.fresh()`
